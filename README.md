Giới thiệu dự án

Sản phẩm này là gì?

Đây là website giới thiệu thông tin cá nhân, các kỹ năng và những dự án học tập. Website được xây dựng nhằm giúp người xem dễ dàng tìm hiểu về bản thân và quá trình học tập.

Demo

https://duc-duy1004.github.io/lab8/

Tính năng

- Giới thiệu thông tin cá nhân.
- Hiển thị kỹ năng và sở thích.
- Giới thiệu các dự án học tập.
- Có menu điều hướng giữa các nội dung.
- Hiển thị hình ảnh và thông tin liên quan.

Cách mở

1. Truy cập đường link Demo ở phía trên.
2. Chờ website tải hoàn tất.
3. Chọn các mục trên thanh menu để xem nội dung.
4. Cuộn trang để xem đầy đủ thông tin và dự án.

Cấu trúc thư mục

- "index.html": Trang chính của website.
- "css/": Chứa các file giao diện.
- "images/": Chứa hình ảnh.
- "docs/": Chứa tài liệu và minh chứng.
- "README.md": Giới thiệu dự án.
- "CHANGELOG.md": Ghi lại các thay đổi.

Đã kiểm tra

- Kiểm tra website trên GitHub Pages.
- Kiểm tra các mục menu điều hướng.
- Kiểm tra hình ảnh và giao diện website.

Chi tiết xem tại "docs/evidence-index.md".

Hạn chế / Chưa kiểm tra

- Chưa kiểm tra trên tất cả các thiết bị.
- Một số giao diện có thể chưa tối ưu trên màn hình nhỏ.
